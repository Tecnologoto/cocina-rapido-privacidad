Política de Privacidad de Cocina Rápido

Última actualización: 23 de noviembre de 2026
Desarrollador: Patricio Fernando Panales Nolasco

La presente Política de Privacidad describe cómo la aplicación móvil Cocina Rápido (paquete com.pfpn.cocinarapido) gestiona y protege la información de sus usuarios.

1. Almacenamiento Local y Privacidad

Cocina Rápido funciona de manera completamente local y sin conexión a internet (offline-first). Toda la información generada o ingresada en la aplicación se almacena exclusivamente en la base de datos interna del dispositivo del usuario (SQLite mediante Android Room). No operamos servidores externos ni transmitimos, vendemos o compartimos datos personales con terceros.

2. Información que se Procesa en el Dispositivo

  • Datos de perfil local: Nombre de usuario y correo electrónico utilizados únicamente para identificar la sesión local dentro del dispositivo.
  • Credenciales de acceso: Las contraseñas se almacenan de forma cifrada mediante el algoritmo criptográfico SHA-256 y nunca se guardan en texto plano.
  • Contenido creado por el usuario: Recetas, listas de ingredientes, pasos de preparación y preferencias guardadas localmente.
  • Sensores del dispositivo (Acelerómetro): La aplicación utiliza el acelerómetro del teléfono exclusivamente en tiempo real para detectar el gesto de agitar el dispositivo en la función "¿Qué cocino hoy?". Los datos del sensor no se graban, almacenan ni envían fuera del dispositivo.

3. Permisos y Servicios de Terceros

Cocina Rápido no contiene publicidad, no utiliza rastreadores analíticos ni integra SDKs de terceros con fines comerciales.

4. Retención y Eliminación de Datos

El usuario tiene control total sobre su información. Puede editar o eliminar sus recetas y datos de perfil directamente desde la aplicación, o bien borrar permanentemente toda la información almacenada desinstalando Cocina Rápido o borrando los datos de la aplicación desde los ajustes de Android.

5. Privacidad de Menores

Esta aplicación está dirigida al público general mayor de 13 años y no recopila de forma intencionada información personal de menores de edad.
